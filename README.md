# nightmarish-phantasm
A demonseed DAW application.

[![Build Status](https://travis-ci.org/illritual999-dot/nightmarish-phantasm.svg?branch=main)](https://travis-ci.org/illritual999-dot/nightmarish-phantasm)
[![License: GPL v3](https://img.shields.io/badge/License-GPL%20v3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

Nightmarish Phantasm aka DEMONSEED is a Digital Audio Workstation (DAW) built with the demonseed framework. It provides a comprehensive set of tools for music production, audio editing, and sound design. This application is designed for musicians, producers, and sound engineers looking for a powerful and flexible creative environment.

*   Multi-track audio recording and editing
*   MIDI sequencing and virtual instrument support
*   Extensive effects processing
*   Plugin support (VST, AU)
*   Real-time audio manipulation

## Installation

To install nightmarish-phantasm, clone the repository and build the project:

```bash
git clone https://github.com/illritual999-dot/nightmarish-phantasm.git
cd nightmarish-phantasm
# Follow build instructions for your specific operating system
```

## Usage

To launch the application after installation:

```bash
# Navigate to the build directory
cd build
./nightmarish-phantasm
```
